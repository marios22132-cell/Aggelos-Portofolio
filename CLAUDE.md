# Angelos Theodorou — Personal Portfolio

## 1. Purpose

A personal portfolio website that is shown **alongside the CV when applying for jobs**. It is a
professional credibility artifact, not an experiment. Every decision — copy, motion, spacing,
performance — is judged by one question: *does this make a hiring manager or recruiter take Angelos
more seriously in the 30 seconds they will spend here?*

- **Audience:** WISP/ISP hiring managers, network/IT infrastructure recruiters, security-adjacent
  employers (the MSc is a forward signal), potential clients needing field installation work.
- **Tone:** confident, concrete, understated. No buzzword soup, no "passionate rockstar ninja".
- **Language:** **English only.** All UI copy, code, comments, commit messages and content are in
  English. (The repo owner communicates in Greek, and the source CV is in Greek, but nothing Greek
  ships to the browser — translate faithfully, never invent.)
- **Primary conversion goals:** download the CV, read the work history, contact by email/phone.

### Structural rules

- **Content lives in `src/lib/content.ts`, never hardcoded inside JSX.** Updating the CV means
  editing one file. Sections map over the data.
- One section = one file in `src/components/sections/`, default-exported, named after its `id`.
- Section wrappers own their vertical rhythm and `id`; children never set page-level padding.
- Anything using hooks, `motion`, or browser APIs starts with `"use client"`. Everything else stays a
  Server Component. Keep client boundaries as low in the tree as possible.

## 5. Design System

Defined once in `src/app/globals.css` under `@theme`. **Never write raw hex values in components** —
use the semantic Tailwind classes generated from the tokens.

### Palette

Near-monochrome warm neutrals with a single signal-blue accent used sparingly (links, active states,
one CTA per screen) — a deliberate nod to wireless/network work, distinct from the overused
purple/blue "AI gradient" look.

| Token | Light | Dark | Use |
|---|---|---|---|
| `background` | `#FAFAF9` | `#0B0B0C` | page background |
| `surface` | `#FFFFFF` | `#141416` | cards, panels |
| `border` | `#E7E5E4` | `#26262A` | hairlines, dividers |
| `foreground` | `#18181B` | `#FAFAF9` | primary text |
| `muted` | `#57534E` | `#A1A1AA` | secondary text (passes 4.5:1 on both) |
| `accent` | `#0369A1` | `#38BDF8` | links, active nav, primary CTA |

Dark mode is a **separately tuned tonal palette**, not an inversion. Both modes must be checked for
contrast; the design is never "done" in only one mode.

### Typography

- Display / headings: **Space Grotesk**, weight 500–700, tight tracking (`-0.02em`).
- Body / UI: **Inter**, weight 400–500, `line-height: 1.6`, max line length ~70ch.
- Scale: `12 / 14 / 16 / 18 / 20 / 24 / 32 / 44 / 64`. Body is **never below 16px**.
- Exactly one `h1` per page (the hero name/role). Heading levels never skip.

### Layout

- Container: `max-w-6xl` with `px-6 md:px-10`, centred.
- Spacing follows a 4px scale — use Tailwind's default steps, no arbitrary values like `mt-[37px]`.
- Section rhythm: `py-24 md:py-32`.
- Breakpoints checked every time: **375 / 768 / 1024 / 1440**. No horizontal scroll, ever.
- Use `min-h-dvh` rather than `min-h-screen` for full-height areas (mobile browser chrome).

## 6. Motion Guidelines (Framer Motion)

Motion here signals craft, so it must feel intentional and calm — never showy.

```ts
import { motion } from "motion/react"   // NOT "framer-motion"
```

Shared variants and timing tokens live in `src/lib/motion.ts`. Use them instead of inventing new
durations per component — the whole site should share one rhythm.

**Rules:**

- Animate **`transform` and `opacity` only.** Never animate `width`, `height`, `top`, or `left`.
- Duration **150–300ms** for micro-interactions, **≤ 500ms** for entrances. Exits run ~60–70% of the
  enter duration.
- Easing: `ease-out` for entering, `ease-in` for exiting. Prefer springs for physical elements
  (the hero portrait, hover lifts).
- Entrances use `whileInView` with `viewport={{ once: true, amount: 0.25 }}` — content must never
  stay invisible if the observer misfires.
- Stagger list/grid children by **40–60ms**. Cap it: at most 1–2 focal animated elements per view.
- **`prefers-reduced-motion` is mandatory.** Use Framer Motion's `useReducedMotion()` and fall back
  to a plain fade or no motion at all. This is an accessibility requirement, not a nicety.
- No parallax, no scroll-jacking, no marquees, no typewriter effects.
- Animation never blocks input, and never delays the first paint of real content.

### Hero animation (the site's one signature moment)

Left column: eyebrow → name → role → short bio → CTAs, staggered upward fade (`y: 16 → 0`).
Right column: the portrait scales/fades in (`scale: 0.94 → 1`, spring, slight delay) inside a rounded
frame with a soft accent glow, plus a very subtle continuous float. The float must be disabled under
reduced motion.

## 8. Quality Bar

Nothing is "done" until `npm run build` passes clean and the checklist below holds.

**Accessibility (non-negotiable):**
- Text contrast ≥ 4.5:1 in **both** light and dark mode.
- Visible focus rings on every interactive element — never `outline: none` without a replacement.
- Full keyboard navigation; tab order matches visual order.
- `aria-label` on every icon-only button (theme toggle, menu toggle).
- Descriptive `alt` text on meaningful images; `alt=""` on decorative ones.
- `prefers-reduced-motion` respected everywhere.

**Performance:**
- Always `next/image` with explicit `width`/`height` (or `fill` + sized parent) to keep CLS < 0.1.
- Hero portrait is the LCP element: mark it `priority`, everything else lazy-loads.
- No layout shift from fonts (`display: swap` via `next/font`).

**Craft:**
- `cursor-pointer` on everything clickable; hover states transition in 150–300ms.
- Responsive at 375 / 768 / 1024 / 1440 with no horizontal scroll.
- Real metadata: title, description, Open Graph, favicon. This link gets pasted into applications.
- Every section works at all breakpoints in both themes before it ships.

**Never:**
- Emoji used as icons.
- Placeholder or lorem-ipsum text left in a commit.
- Invented CV facts.
- Raw hex colours inside components.
- A second animation or CSS library.
